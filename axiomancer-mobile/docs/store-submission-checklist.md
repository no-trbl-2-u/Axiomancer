# Store Submission Checklist

## Pre-Submission Requirements

### App Metadata
- [ ] App title finalized and consistent across platforms
- [ ] App description written and reviewed for both stores  
- [ ] Keywords researched and optimized for discoverability
- [ ] App categories selected (Games > Role Playing)
- [ ] Age rating completed (ESRB/PEGI equivalent)
- [ ] Privacy policy URL accessible and compliant
- [ ] Support contact information provided

### App Store Connect (iOS)
- [ ] Developer account in good standing
- [ ] App Store Connect Agreement accepted
- [ ] Tax and banking information completed
- [ ] App ID created and configured
- [ ] Production signing certificates valid
- [ ] TestFlight internal testing completed
- [ ] App Store Review Guidelines compliance verified

### Google Play Console (Android)
- [ ] Google Play Developer account active
- [ ] Play Console Developer Agreement accepted
- [ ] Merchant account setup (if applicable)
- [ ] App signing key configured
- [ ] Play Internal Track testing completed
- [ ] Google Play Developer Policy compliance verified

## Asset Requirements

### Screenshots
- [ ] iOS screenshots: 1290x2796 (iPhone Pro Max) ✓
- [ ] iOS screenshots: 1179x2556 (iPhone) ✓  
- [ ] iOS screenshots: 2048x2732 (iPad Pro) if applicable
- [ ] Android screenshots: 1440x2560 (Phone) ✓
- [ ] Android screenshots: 1920x1200 (Tablet) if applicable
- [ ] All screenshots show actual gameplay
- [ ] Screenshots are high quality and properly formatted

### Icons and Graphics
- [ ] iOS app icon: 1024x1024 PNG ✓
- [ ] Android adaptive icons: 1024x1024 foreground/background/monochrome ✓
- [ ] Web favicon: 192x192 PNG ✓
- [ ] All icons follow platform design guidelines
- [ ] Splash screen assets properly configured ✓

## Build Requirements

### Production Builds
- [ ] EAS Build production profile configured ✓
- [ ] iOS production build completes without errors
- [ ] Android production build (AAB) completes without errors
- [ ] Build sizes within platform limits (iOS <4GB, Android <150MB)
- [ ] All required permissions and entitlements included
- [ ] Production signing and certificates valid

### Code Quality
- [ ] All tests passing (`npm run verify`) ✓
- [ ] No debug code or development artifacts in production
- [ ] Performance optimized for production environment
- [ ] Error handling implemented for all user flows
- [ ] Accessibility features implemented and tested

## Content Review

### App Store Review (iOS)
- [ ] No restricted content or functionality
- [ ] In-app purchases properly configured (if applicable)
- [ ] External links and services comply with guidelines
- [ ] User-generated content policies addressed (if applicable)
- [ ] App functionality matches description and screenshots

### Google Play Review (Android)
- [ ] Content rating questionnaire completed accurately
- [ ] No prohibited content or functionality
- [ ] Permissions requested are justified and documented
- [ ] Target API level meets current requirements
- [ ] App Bundle optimization enabled

## Legal and Compliance

### Privacy and Data
- [ ] Privacy policy covers all data practices ✓
- [ ] GDPR compliance addressed (if applicable)
- [ ] CCPA compliance addressed (if applicable)
- [ ] Children's privacy (COPPA) compliance verified ✓
- [ ] Data collection practices clearly documented

### Platform Policies
- [ ] Apple App Store Review Guidelines compliance
- [ ] Google Play Developer Policy compliance
- [ ] Content policies reviewed for TTRPG/gaming content
- [ ] Intellectual property rights verified
- [ ] Third-party licenses documented (if applicable)

## Testing and Quality Assurance

### Internal Testing
- [ ] TestFlight beta testing completed with team feedback
- [ ] Play Internal Track testing completed with team feedback
- [ ] All major bugs fixed or documented
- [ ] Performance testing completed on target devices
- [ ] Accessibility testing completed

### External Validation
- [ ] User acceptance testing with target audience (if applicable)
- [ ] Security review completed (if applicable)
- [ ] Third-party integrations tested (if applicable)

## Submission Process

### iOS Submission
- [ ] App information complete in App Store Connect
- [ ] Build uploaded and processed successfully
- [ ] Export compliance information provided
- [ ] Advertising identifier usage declared
- [ ] App review information and notes provided
- [ ] Release options configured (manual/automatic)

### Android Submission
- [ ] App details complete in Play Console
- [ ] AAB uploaded to Internal Track successfully
- [ ] Content rating completed
- [ ] Pricing and distribution configured
- [ ] Release notes written for initial release
- [ ] Rollout percentage set appropriately

## Post-Submission

### Monitoring
- [ ] App review status monitoring setup
- [ ] Crash reporting and analytics configured (if applicable)
- [ ] User feedback monitoring planned
- [ ] Update process and timeline established

### Launch Preparation
- [ ] Internal team notified of submission
- [ ] Documentation updated with store URLs (post-approval)
- [ ] Marketing materials prepared (if applicable)
- [ ] Support processes established for user questions

## Review Guidelines Reference

### Apple App Store
- Safety: No objectionable content
- Performance: Stable, responsive, production-ready
- Business: Clear value proposition
- Design: Native platform experience

### Google Play
- Content: Age-appropriate and policy-compliant
- Functionality: Works as described
- User Experience: Intuitive and accessible
- Safety: Secure and respectful of user privacy
