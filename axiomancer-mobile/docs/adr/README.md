# Axiomancer Mobile Architecture Decision Records

ADRs capture durable mobile-client decisions. They sit above build plans and below T's latest explicit decision / company CDRs.

## Source-of-truth hierarchy

1. T's latest explicit decision.
2. CDRs / ADRs.
3. Central SomberSoft ledger.
4. Active build plan.
5. Phase candidates.
6. Critique/audit logs.
7. Historical reports.
