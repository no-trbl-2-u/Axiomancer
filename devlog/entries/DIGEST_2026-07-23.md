## [infra] Telemetry rows now travel with the commits that produced them

**What:** a tracked `.githooks/pre-commit` auto-stages `TELEMETRY.md`
into every commit that changes it, `.githooks/pre-push` blocks a push
if newer telemetry rows are still uncommitted, and session startup
wires both in via `git config core.hooksPath .githooks`.
**Why:** "TELEMETRY.md is generated residue, but it belongs to the
code change that produced it" (from the new hook's own comment) — the
07-22 14:30 `march` tick that shipped the title-screen fix left its
`skill`/`subagent` telemetry rows stranded outside that commit, which
is exactly the failure mode this closes.
```diff
--- /dev/null
+++ b/.githooks/pre-commit
@@ -0,0 +1,12 @@
+#!/bin/sh
+set -eu
+repo_root=$(git rev-parse --show-toplevel)
+cd "$repo_root"
+if [ -n "$(git status --porcelain -- TELEMETRY.md)" ]; then
+  git add -A -- TELEMETRY.md
+  printf '%s\n' 'pre-commit: staged TELEMETRY.md alongside this commit.' >&2
+fi
```
