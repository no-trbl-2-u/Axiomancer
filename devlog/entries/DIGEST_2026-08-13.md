## [mechanics] Phase 52c — rest-choice engine (heal / anvil / cut)

**What:** a new pure `World/RestChoice` engine models a rest node as one
irreversible pick of three offers — `rest` (free, partial camp heal or
full+mend inn), `anvil` (50 shillings, one hone-or-temper, composing the
existing `World/Blacksmith` engine for die-gear-cap legality only), or
`cut` (escalating price, one deck removal, composing Phase 52a's
card-removal pricing) — committing one locks the other two. The engine
never touches `GameState` or calls `removeCardFromCombatDeck` itself; it
hands the host a claim-time outcome ledger to apply against the real
`Character`.
**Why:** resolves the standing `[needs-user-call]` on blacksmith map
placement/cadence — the anvil is reached through the rest node, never as
a standalone map node. The Night Watch stays live and untouched; 52d
wires the mobile screen and 52e retires it only once the replacement is
reachable.
**Commits:** `e1ae8318` (ship), `2ecdba6f` (row)
