kb-query

Hosted MCP server over the SomberSoft game-knowledge-base corpus (board-game rules & reception, Dawncaster cards/keywords).

MCP endpoint: POST /mcp (streamable HTTP, stateless JSON). Tools: kb_overview, kb_find_games, kb_search, kb_read_doc, kb_cards, kb_keyword.

Source & docs: kb-mcp-host/ in the Axiomancer repo.
