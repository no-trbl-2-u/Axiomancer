## Scope resolution (the row read wider than the actual work)

The row name-drops `C-01` and `S-01` but neither is this phase's content to
author:

- **`C-01` (The Sophist)** is gated on `W-01` (the Aporia labyrinth
  continent) implementation, not shipped yet. Its quest-board content
  (`SOPHISTS_FIRST/SECOND/THIRD_LEDGER_BOARD` in `quest-board.content.ts`)
  is **already authored and already voice-compliant** — cold, terse,
  correctly uses the NL-9 proper-noun carve-out for "Sophist"/"premise"/
  "lemma". Nothing to do here.
- **`S-01`** (the four fishing-village/Northern-Forest dilemmas) is
  explicitly queued as build-plan **Phase 53d** ("Author S-01's four
  dilemmas"), still `[ ]`. Authoring new dilemma content here would
  duplicate that phase's job.
- **`S-02-fishing-village-voices.md`** (read in full) is the spec that
  actually names this phase's job, in its own words: *"The eight coastal
  trees were written before Phase 42's Profane Canon: they carry
  exclamation marks, 'Bless you, kind soul', and inline meter readouts like
  `[Moral meter +5]` in the body text. **Phase 44g owns rewriting them** —
  that phase already names S-01 and 'dialogue trees' as its scope. This
  spec deliberately does not retheme a single existing line."* And Phase
  44f's own brief (already shipped) deferred exactly one thing to 44g by
  name: `quest-board.content.ts`'s `storyBeat` string ("Fishing Village —
  Main Quest: ...").

So the actual, bounded scope this run:

1. **Retheme the prose** (narrator text + NPC lines + player choice labels)
   in all eight authored coastal-village dialogue trees to match spec 34
   §2's ratified register — terse, archaic, cold and old; no exclamation
   marks; no explanatory bracket readouts (`[Moral meter +5]`); no modern/
   corporate register ("business philosophy", "competitive market",
   "collective action").
2. **Rename the quest-board `storyBeat` display string** — `Fishing
   Village` → `the Drowned Parish`, mirroring 44f's region-name precedent
   exactly (same worked example, NL-18).

## Decisions made upfront — DO NOT ASK

- **Structure, flags, deltas, node ids, `nextNodeId` links, `requires`
  gates are byte-for-byte unchanged.** This is a prose-only retheme, per
  S-02's own framing ("it changes what they say," not which lines a player
  can reach — that's 53a-53c). Touching `moralDelta`/`alignmentDelta`
  values or flag names would silently break the reactive web Phase 53e is
  planned to build on top of these exact flags.
- **NPC identities (names) are unchanged.** Old Marrow, the Coastal Beggar,
  Captain Blackwater, the Fisherman's Daughter, the Village Healer, the
  Dockworker's Union Leader, the Merchant's Widow, the Tide-Shopkeeper are
  all already used as canonical identifiers in S-02 (a ratified spec) and
  read as compliant under NL-19 (folk name + trade tag, or office + the
  definite article). No naming-law renames needed for this row.
- **`oldDockmasterTree` (Old Marrow) is already compliant** — no
  exclamation marks, no brackets, already terse/archaic (Phase 63 already
  wrote it against a voice bar close to spec 34's). Left untouched except
  where a line reads as filler that a full pass should tighten.
- **`tideshopkeeperTree` is a one-line stub** ("Saltwater hardtack and
  twine. Coin only.") already compliant; the shop UI itself stays out of
  scope per S-02 (Tide-Shopkeeper is one of the "unhomed four").
- **`fvFatherWorryDialogue` and the arrival cutscene in `content.ts` are
  already compliant** — no violations found (checked for `!`, brackets,
  banned-register words). Not touched.
- **`fvShoreInteraction`'s `npcName: 'Weathered Fisher'` mismatch is not
  this phase's to fix** — S-02 files it as a roster mismatch for Phase 53a
  ("the guard, then the mismatches"). 44g owns prose, not wiring.
- **The Sophist's quest-board boards (`SOPHISTS_*_LEDGER_BOARD`) are not
  touched** — already voice-compliant, correctly scoped to W-01, out of
  this phase's actual (S-02-derived) surface.
- **No `docs/lexicon.json` row.** Same reasoning 44f used: "Fishing
  Village" stays the correct working name in specs, `plan/` history, and
  test descriptions; only the one live UI-adjacent display string
  (`storyBeat`) changes.
