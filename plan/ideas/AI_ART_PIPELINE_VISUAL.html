1 · Sources of truth (existing repo)

MECHANICS Content libraries

enemy.library.ts (~73) · cards.library.ts (~71) · equipment · world content

SPECS Character / story / world specs

specs/characters/ · specs/story/ · specs/world/ — flavor & description text

STYLE/V1 Style bible

STYLE.md + 8–12 canonical reference images — the cold-codex woodcut/ink look, frozen & versioned

▼
2 · Compile (deterministic, in-repo)

ART:STATUS art.manifest.json

Scraped registry of every art-bearing entity: slug, category, status (missing / temp / final). Makes the gap queryable.

SOURCE CODE Prompt files

prompts/<category>/<slug>.md — authored once per subject, reviewed & diffable

COMPILER Prompt compiler

style preamble + category template + entity description → final prompt

▼
3 · Generate (the only swappable stage)

ADAPTER Generator interface

generate(slug, prompt, refs, n) → candidates/ — one seam, four implementations: openai · comfyui · scenario · recraft. See “Generator backends” tab.

▼
4 · Judge

CLAUDE Vision pre-screen

Grades candidates against STYLE.md — palette, composition, artifacts. Fails re-queue automatically.

HUMAN Contact-sheet review

art:review — static HTML grid, category neighbors alongside. Human picks winners; choices recorded.

▼
5 · Post-process (automates today’s manual recipe)

SHARP trim → alpha-matte → glow → resize → WebP

Luminance-keyed alpha on black, graded glow edge, ≤512–640px, q≈80, >150 KB warning. Deterministic, idempotent, fixture-tested.

▼
6 · Ingest & record (existing contract, now scripted)

APP assets/images/<cat>/

File landed + that directory’s index.ts slug registry updated

LEDGER provenance.json

Backend, model+version, prompt hash, style version, refs, seed/workflow hash, date, original archive path. Doubles as the AI-disclosure record.

GATE verify:visual

Existing mobile visual gate covers in-app rendering, as usual

The pipeline never changes between these — only the adapter behind generate(slug, prompt, refs, n) does. Recommended path: A now, B when style drift bites; A’s curated output becomes B’s LoRA training corpus, so nothing is wasted.

  • Write STYLE.md, commit 8–12 reference images (style/v1)
  • Manifest scraper + art:status gap report

art-2 · Pipeline build~1 week of evenings

  • tools/art-pipeline/: compiler, openai adapter, sharp post-process, ingest + provenance + registry writer, contact-sheet tool
  • OpenAI API billing; keys in env; per-batch cost log

art-3 · Backfill~2–3 weeks calendar · ≈$20–90 total

  • Batches of 10–15 subjects × 3 candidates: cards gap (~50) → enemies gap (~19) → worst temp art → portraits → backgrounds → treasure
  • Ingest tmp-images/ walls/doors through the same post-process

art-4 · Consistency upgrade (optional)when drift bites

  • Curate 20–50 best images → train axiomancer-codex-v1 LoRA (FLUX.2 klein 4B, local or rented GPU)
  • comfyui adapter with fixed seeds in provenance; re-run the art-1 test set; flip default backend if it wins

art-5 · Icons + ship hygienewith UI icon work

  • Recraft custom style → burn down the SVG_ASSET_SPEC.md icon backlog (~$0.07/vector)
  • Pre-ship store-policy re-check; Steam disclosure (if ever) filled from provenance.json
