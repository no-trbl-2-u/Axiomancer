## Scope resolution

Spec 34 §6 already rules every naming/shape decision this phase needs —
there is no open design question left, only implementation:

- **§6.1** — spec 10 (`moralMeter`) is kept and re-skinned. Display name
  **GRACE**, three bands: **In Arrears** (≤ -34) / **Indifferent** /
  **In Grace** (≥ +34). Engine field `moralMeter`, reducer
  `shiftMoralMeter`, the ±1/±5/±10 delta bands, the friendship +1, the
  evil-path reward-scaling rule — all mechanically untouched.
- **§6.2** — spec 14 (the alignment cube) is kept and re-skinned. Display
  name **THE OATHS**. Axes rename for display only: `epistemology` →
  **CREED** (Faith ◀ Doubt ▶ Evidence), `outlook` → **AUGURY**
  (Dread ◀ Endurance ▶ Hope), `scope` → **TROTH** (Self ◀ Kin ▶ Saints).
  Thresholds (`±34`), the 27-cell shape, enemy alignments, the
  outlook-bias AI, and the dialogue/skill gates are untouched.
- **§6.2.1** — the 27 cells' content re-skins field by field:
  `philosopher` → **damned exemplar**, `literaryCharacter` → **cautionary
  tale**, `fallacies` → **besetting sins** (`AlignmentFallacy` type
  renamed `BesettingSin`, same 3-field shape).
- **§6.2.2** — persisted keys frozen (`GameState.philosophicalAlignment`,
  `SHIFT_PHILOSOPHICAL_ALIGNMENT`, the 27 cell ids). The *module*
  `src/Philosophy/` renames to `src/Ledger/` — internal only, zero
  persisted-state risk. `docs/philosophy.md` → `docs/oaths.md`.
- **§6.3** — the two systems (GRACE, THE OATHS) stay orthogonal. No
  change to that relationship.
- **§6.4** — the successor premise ("What you owe, and to whom, is a
  mechanical input") is **44i's** to write into `spec.md` / bearings, not
  this phase's.

**No `GAME_STATE_VERSION` bump.** Every rename here is display-only or
internal-module-only; nothing touches a persisted field name, action
type, or cell id (§0.4, §6.2.2).

### A stale sub-row this phase's own text raises, and resolves

§6.2.1's last sentence says "the four fallacy-sourced skills and three
fallacy-sourced effects ... are re-authored as sins." Checked against the
live tree: **none of the seven exist.** `nirvana-fallacy`,
`appeal-to-consequences`, `pascals-wager`, `appeal-to-fear`,
`debuff_no_true_scotsman`, `buff_special_pleading`,
`debuff_category_error` are absent from `src/Skills/` and `src/Effects/`
— the Profane Canon rework (`84ef85b`) deleted the spec-32 card library
they belonged to before this phase ever ran (the same kind of staleness
spec 34 §5.9.1 already found and corrected for 44c's row). `sourcedFromCell`
still exists as a field on `Effects/types.ts` but nothing sources from it.
Nothing to re-author; noted in `docs/oaths.md` so a future content phase
doesn't go looking for names that no longer exist.

### The 27-cell content authoring — done in-phase, not deferred

Spec 34 §10 residue item 8 explicitly permits splitting the 27-damned-
exemplar / 27-cautionary-tale / 81-besetting-sin authoring into its own
content phase "if 44h runs long." Given the volume (27 cells × 5 fields)
is exactly the kind of parallelizable content-authoring work the loop's
sub-agent delegation exists for, this run authored all 27 cells in-phase
(three parallel sub-agent passes of 9 cells each, grounded in spec 34 §1
"The Parish", §2 tone/voice, §3 naming law) rather than deferring. No
follow-up content phase is needed for the cube's own library.

### "The character screen's history list" — resolved against the live tree

§5.6's closing sentence ("the character screen's history list becomes THE
ACCOUNT; the /memoir tab becomes THE LEDGER; the REMAINS section keeps
its name") names three surfaces. Checked against the live tree:

- **"The character screen's history list"** is the collapsible
  `MORALE · LEDGER` breakdown on `app/(tabs)/character/index.tsx`
  (gain/loss rows: "+i every victory", "−ii flee combat", etc.) — the
  only history/journal-shaped list that screen has. Renamed to
  **THE ACCOUNT** (drops the MORALE/GRACE prefix per the ruling's literal
  wording).
- **"The /memoir tab"** is the tab-bar label, `TAB_TITLES.memoir` in
  `state/presenters/tabs.engine.ts` (currently `'MEMOIR'`, the one
  tab-bar slot the Phase 32/33 handoff-port rename pass left generic
  next to WILDS/STRIFE/SELF/SATCHEL). Renamed to **THE LEDGER**. The
  in-screen header eyebrow ("✠ THE BOOK OF DEEDS") is a distinct surface
  not named by this ruling — left untouched.
- **REMAINS** — unchanged, per the ruling.

### "THE BENT" — a naming collision this phase found and cleaned up, not ruled by spec 34

`state/presenters/memoir.engine.ts` has a **second, unrelated** concept
that also calls itself "philosophical alignment" — a dominant-base-stat
heuristic (`heart`/`body`/`mind`, "of the Heart" / "of the Body" /
"of the Mind") entirely distinct from THE OATHS cube (it reads
`player.baseStats`, never `state.philosophicalAlignment`). Spec 34 §6
doesn't rule on it by name. Decision: its visible tooltip title
(`PHILOSOPHICAL DOMINANCE`) still says "philosophical," which now reads
as a stray leftover of the retired theme sitting right next to the real
THE OATHS chip on the same memoir screen — retitled **THE BENT** (an
archaic word for natural inclination, folk-register, no collision).
Internal identifiers (`PhilosophicalAlignment` local type,
`buildPhilosophicalAlignment`, `emptyPhilosophical` VM field) are left
alone — not player-visible, and renaming them is churn per §0.3 (this
mirrors the pattern used throughout spec 34: ids/internal names frozen,
display copy only).
