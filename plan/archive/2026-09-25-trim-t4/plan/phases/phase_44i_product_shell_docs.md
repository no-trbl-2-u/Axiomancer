## Scope resolution

This is the closing phase of the 44-series. Everything else (cards, keywords,
themes, enemies, world, story, morality) is already re-skinned; this phase
only updates the prose that describes the *product*, not any mechanic.

- **§6.4** — the successor premise for `spec.md` / bearings:
  > **What you owe, and to whom, is a mechanical input.**
  Replaces "your worldview is a mechanical input" everywhere it appears as
  the product thesis. THE OATHS and GRACE are the mechanism (unchanged); only
  the framing sentence changes.
- **§7** — "campaign" is descriptive of the shipped arc (`threadbare →
  pilgrim → apostate`, §1.4), not a new run/meta-progression system. `spec.md`
  may say "dark fantasy deckbuilding RPG campaign"; it may not describe or
  imply new engine work.
- **§5.6** — the copy canon: VITAE (keep), STANCE (keep), MORALE → GRACE
  (done in 44h for the meter's primary surfaces; this phase closes out
  leftover player-facing "morale" strings the 44h sweep missed, and updates
  the bearings Copy canon bullet, which never got a GRACE line).
- **§2 / §2.1** — the Voice register is RATIFIED, not replaced. The bearings
  Voice bullet's "Theme-bearing, pending Phase 42" parenthetical is now
  discharged and is dropped, not the rule itself.

### What this phase does NOT do

- No mechanic, payload, constant, or resolver changes (§0.1 — this spec has
  no authority over mechanics).
- No new run/meta-progression system (§7.2 — filed as a phase candidate, not
  built here).
- No further card/keyword/enemy/world/story renames — those were 44a-44g's
  job and are done.
- `axiomancer-mechanics/src/Ledger/` internal field names
  (`philosophicalAlignment`, `PhilosophicalAlignment` type, etc.) stay
  unchanged per §6.2.2 — persisted keys don't move. Only player-visible copy
  and the product-level docs move.

### Found in survey, judgement calls

- **`axiomancer-mechanics/VISION.md` and `axiomancer-mobile/VISION.md`** each
  carry the same retired "philosophy RPG" identity line spec.md is being
  rewritten away from. Neither file is named in spec 34's §9 table for 44i,
  but §0.1 says the spec "outranks every prose surface written before
  2026-08-08 on questions of fiction, name and register," and leaving the
  doctrine docs stating the premise `spec.md` no longer states would be a
  worse inconsistency than a two-line fix. In scope, done opportunistically.
- **`axiomancer-mechanics/docs/api.md`'s "Philosophy" section heading**
  (line ~492) still names `AlignmentFallacy`, a type 44h renamed to
  `BesettingSin` — a leftover factual bug from 44h's docs sweep, not a new
  rename decision. Fixed as a drive-by correction, not a new naming call.
- **Leftover player-facing "morale" strings** (FLEE/WITHDRAW subtitles, the
  event consequence label, the flee toast, the HEART stat tooltip) were
  missed by 44h's MORALE→GRACE sweep, which focused on the character/memoir
  screens. These are squarely inside §5.6's obligation; swept here.
- **Not touched:** internal-only identifiers (`vm.philosophicalAlignment`
  a11y strings tied to the kept engine field, `moraleRow`/`moraleDisplay`
  style/variable names, `DebugAlignmentShift.tsx`) — churn per §0.3, and the
  engine field itself is frozen by §6.2.2. Also not touched: world/NPC
  flavor text (e.g. northern-forest "a philosopher tends a small fire") —
  that's 44f/44g content-authoring territory, not product-shell prose.
  `specs/README.md`'s missing spec-34 row is pre-existing residue already
  filed to `plan/AUDIT.md`, not this phase's file.
