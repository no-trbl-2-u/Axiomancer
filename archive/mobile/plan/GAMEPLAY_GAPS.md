## Gap Classification

**Priority Scale:**
- 5 = Blocks core gameplay, prevents player success
- 4 = Significantly impacts player experience and decision making  
- 3 = Important quality of life, affects engagement
- 2 = Minor convenience, polish-tier
- 1 = Cosmetic or edge case

**Status:**
- CONFIRMED = Verified through manual codebase analysis
- NEEDS_VERIFICATION = Identified via automated analysis, requires validation
- ADDRESSED = Previously existed but resolved in recent phases

## Active Gaps (Confirmed)

### GAP-001: Complete Absence of Tutorial/Onboarding
- **Priority:** 5
- **Systems Affected:** New player onboarding, core mechanic learning, UI navigation
- **Description:** No guided introduction to game systems. Players dropped into complex UI without context.
- **Reproduction Steps:**
  1. Fresh app install
  2. Launch game
  3. Observe lack of tutorial or system introduction
- **Observable Symptoms:** Immediate confusion, inability to understand basic gameplay loop
- **Implementation Approach:** Lightweight intro sequence covering: exploration → encounter → combat → progression
- **Effort Estimate:** Medium (3-5 days) - UI flow + content creation
- **Dependencies:** Design decisions on tutorial scope and presentation style

### GAP-002: Quest/Objective System Missing  
- **Priority:** 4
- **Systems Affected:** Player motivation, narrative progression, goal tracking
- **Description:** No long-term objectives or quest structure beyond immediate encounter resolution
- **Reproduction Steps:**
  1. Play through multiple encounters
  2. Look for overarching goals or quest indicators
  3. Attempt to understand larger purpose
- **Observable Symptoms:** Aimless wandering, lack of long-term motivation
- **Implementation Approach:** Basic quest system with simple goals (defeat X enemies, explore Y nodes)
- **Effort Estimate:** Large (1-2 weeks) - New data structures + UI integration
- **Dependencies:** Game design decisions on quest complexity and narrative integration
- **Code Notes:** `memoir.engine.ts` has placeholder quest tracking infrastructure

### GAP-003: Equipment Stat Preview Missing

### GAP-005: Save/Persistence Transparency Missing

### GAP-006: Encounter Risk Assessment Absent

- **Description:** No relative strength indicators for encounters, preventing informed fight vs flee decisions
- **Reproduction Steps:**
