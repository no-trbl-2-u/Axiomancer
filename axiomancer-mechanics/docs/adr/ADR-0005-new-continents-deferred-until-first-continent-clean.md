# ADR-0005 — New continents deferred until first continent is clean

Status: Accepted  
Date: 2026-06-01  
Scope: axiomancer-mechanics

## Decision

New continent work is deferred indefinitely until the first continent / base mechanics are clean, balanced, and playable.

## Context

T deferred new-continent work after balance failure evidence. Expansion before a clean first continent would multiply content debt.

## Consequences

- Phase 100 Northern Continent remains `[deferred]` until a future explicit T decision reopens it.
- Balance, first-continent playability, combat/friendship loops, and evidence harnesses outrank map expansion.
- Phase candidates proposing broad geography must be gated against this ADR.
