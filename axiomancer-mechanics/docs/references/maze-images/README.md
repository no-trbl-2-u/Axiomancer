# MAZE book images

These images are copied from Al Sweigart's `mazewebsite` repository:

- Source repository: https://github.com/asweigart/mazewebsite
- Source path: `mazewebsite/images/`
- Source commit used for this copy: `5d2f59e`

They are direct images from Christopher Manson's *MAZE: Solve the World's Most Challenging Puzzle* and are kept here as reference material for Axiomancer's Labyrinth / Aporia design work.

Files whose names contain `thumb` were intentionally excluded.

Do not treat this directory as final game art. It is source-reference material for studying room composition, visual clue placement, door numbering, and puzzle grammar.
