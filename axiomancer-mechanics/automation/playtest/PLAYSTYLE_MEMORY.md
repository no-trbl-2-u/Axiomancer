# Playstyle Memory

This file records how automated playtest witnesses should behave. It is not combat doctrine; it is witness calibration so balance evidence does not condemn mechanics through incompetent bots.

## Canonical witnesses

- **AGGRESSIVE**: press damage, build Body resources through attacks, and spend affordable enemy-targeting skills immediately. It should not hoard resources or stall behind defensive loops.
- **DEFENSIVE**: preserve HP with items/defend when genuinely pressured, but still convert safe windows into damage through skills and attacks. When wounded, it may defend in Heart to stabilize instead of turning Body-defense into a bunker or a bad matchup. It is a survival witness, not a bunker doctrine.
- **MIXED**: rotate through aggressive, defensive, and strategist intentions so broad ordinary play remains viable.
- **STRATEGIST**: prove the intended skill/status mastery route. It should prioritize high-value skills, status effects, synergies, Tier 3 chains, and stance/resource planning instead of repeating basic Body attacks forever.

## Current calibration note — 2026-06-05

Phase 121 evidence showed stale witnesses: all canonical policies overused Body stance, and STRATEGIST/AGGRESSIVE spent almost exclusively on `ad-hominem-strike`. The current policy calibration scores target-facing damage, tier, status effects, special mechanics, and synergies, then builds stance resources toward higher-value chains such as `achilles-gambit`, `sorites-cascade`, and `straw-giant`.

Expected evidence after this calibration:

- Skill use should include multiple higher-tier/status skills, not only `ad-hominem-strike`.
- Stance use should include Mind when building or firing Mind skills.
- STRATEGIST should outperform blunt attack repetition on normal anchors.
- DEFENSIVE should survive without converting every run into a timeout.
